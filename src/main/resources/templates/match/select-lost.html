내 분실물 글 선택

이 습득물이 본인의 물건이라고 생각되면, 먼저 본인이 등록한 분실물 글을 선택해 주세요.
선택한 분실물 글과 습득물 글의 정보를 비교한 뒤 유사도 결과를 확인합니다.

수령 신청 흐름

분실물 글 선택 → 유사도 확인 → 보관 장소 안내 순서로 진행됩니다.

1
분실글 선택 본인이 등록한 분실물 글을 선택합니다.
2
유사도 확인 물건명, 위치, 시간, 특징을 비교합니다.
3
보관장소 안내 관리자 확인 후 수령 장소를 안내받습니다.
분실물 글 등록이 필요합니다. 습득물을 수령하려면 먼저 본인의 분실물 글이 등록되어 있어야 합니다. 분실물 글에 작성한 색상, 위치, 시간, 고유 특징을 바탕으로 유사도를 확인합니다.
