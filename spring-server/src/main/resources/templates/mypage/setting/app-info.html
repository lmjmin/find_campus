서비스 소개

FindCampus는 동명대학교 캠퍼스 안에서 발생하는 분실물과 습득물을 사용자가 쉽게 등록하고 확인할 수 있도록 만든 서비스입니다. 물건명, 카테고리, 위치, 날짜 정보를 기준으로 분실물과 습득물을 확인할 수 있으며, 유사 물건 추천 기능을 통해 사용자가 잃어버린 물건을 더 빠르게 찾을 수 있도록 돕습니다.

주요 기능

분실물 등록 잃어버린 물건의 이름, 위치, 특징을 등록합니다.
습득물 확인 등록된 습득물을 확인하고 수령 신청을 진행합니다.
유사 물건 추천 분실물과 습득물의 정보를 비교해 비슷한 물건을 확인합니다.
캠퍼스 위치 검색 캠퍼스 건물과 장소를 기준으로 물건을 찾습니다.
