습득물 등록

주운 물건을 간단히 등록해 주세요. 자세한 본인 확인은 분실자가 수령 신청할 때 진행됩니다.

등록은 간단하게, 반환은 안전하게

습득자는 빠르게 올리고, 분실자가 자세히 증명하는 방식으로 진행합니다.

1
간단 등록 물건명, 장소, 날짜, 사진만 입력해도 등록할 수 있습니다.
2
분실자 수령 신청 분실자가 본인만 알 수 있는 특징을 작성합니다.
3
확인 후 수령 관리자 확인 뒤 안전하게 물건을 찾아갑니다.
습득자는 자세히 적지 않아도 괜찮아요. 남의 물건을 대신 올려주는 것이기 때문에 복잡한 정보를 요구하지 않습니다. 물건의 기본 정보와 사진만 등록해도 분실자가 나중에 본인 확인 정보를 입력할 수 있습니다.
본인 확인은 이렇게 진행돼요
습득자 물건을 간단히 등록합니다.
분실자 색상, 무늬, 흠집 등 본인 물건의 특징을 자세히 작성합니다.
관리자 신청 내용과 실제 습득물을 비교한 뒤 승인합니다.

물건 정보

정확한 모델명까지 몰라도 괜찮습니다. 물건 종류만 적어도 됩니다.

사진은 분실자가 물건을 찾는 데 가장 큰 도움이 됩니다. 이름, 학번, 전화번호 등 개인정보가 보이면 가린 뒤 업로드해 주세요.

고유한 특징을 모두 글로 적지 않아도 됩니다. 분실자가 수령 신청할 때 직접 특징을 설명하고, 관리자가 실제 물건과 비교합니다.

부담 없이 간단히 작성하세요. 색상이나 대략적인 모습 정도만 적어도 됩니다.

습득 위치

기억나는 만큼만 적어도 됩니다.

보관 정보

가능한 한 학교 담당 부서나 안내데스크에 맡겨 주세요.

이 게시글만 보고 바로 물건을 가져갈 수는 없습니다. 분실자는 수령 신청 시 본인만 알 수 있는 특징을 작성해야 하며, 관리자 확인 후 수령 절차가 진행됩니다.
