선택한 분실물 글과 습득물 글의 정보를 AI가 비교해 유사도 결과를 확인합니다.

수령 신청 흐름

분실물 글 선택 → AI 유사도 확인 → 보관 장소 안내 순서로 진행됩니다.

1
분실글 선택 본인이 등록한 분실물 글을 선택합니다.
2
AI 유사도 확인 AI가 물건명, 위치, 날짜, 특징을 비교해 유사도를 계산합니다.
3
보관장소 안내 보관처의 확인 절차를 안내받습니다.
